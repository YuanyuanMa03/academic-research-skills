## 二、发现并修复的问题（PR #7，已合并）

1. **nature-citation 0 候选根因修复**（最重要）：期刊过滤下推到 CrossRef API 层，`scope_containers()` 按 scope（nature/science/cell/cns/flagship）轮询容器词，`in_scope()` 保留为精确性兜底。验证：perovskite claim 0→3 条真实 Nature Energy 文献；原课题 CNS scope 命中 3 条。
2. **nature-citation 空结果提示**：0 导出时 stderr 说明可能原因（scope 太窄/措辞太窄/网络），空结果显式声明为合法结果而非崩溃。
3. **nature-academic-search mailto 引导**：SKILL.md 补 `OPENALEX_MAILTO` 环境变量与"裸跑必 429，带 --mailto 立即可用"的实测注记。
4. **scansci-pdf Zotero 事实修正**：`zotero_push` 需要 zotero.org 的 **Web API key**（在网页设置创建），与本地 Zotero 程序无关——SKILL.md 与 REFERENCE 排障表均已改正。
