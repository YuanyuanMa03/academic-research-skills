# Paper Detail Report Template

## Standard Output Contract

All paper detail skills should produce output in the following format:

```
# {title}

## Metadata
- Authors: {authors}
- Journal: {journal} ({year})
- Volume: {volume}, Issue: {issue}, Pages: {pages}
- DOI: {doi}
- ISSN: {issn}
- Language: {language}

## Abstract
{abstract}

## Keywords
{keywords}

## Citation Metrics
- Citations: {citation_count}
- {platform_specific_metrics}

## References ({ref_count})
1. {ref_title} ({ref_authors}, {ref_year})
2. ...

## Full Text
- PDF URL: {pdf_url}
- {availability_status}
```

## Platform-Specific Metrics

| Platform | Extra Metrics |
|----------|---------------|
| WoS | JIF, JCR quartile, Research Areas, WoS Categories |
| CNKI | Downloads, CIF, AIF, CLC Code, Foundation |
| GS | Cited by count, Related articles |
| SD | Article type, Open access status |
| Nature | Altmetric score, Peer review history |
